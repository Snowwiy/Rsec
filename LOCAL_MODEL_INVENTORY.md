# Inventario privado de modelos

Biblioteca del propietario pendiente de acceso. Reutilización en ese equipo: indeterminada. El inventario de prueba se ejecutó contra los artefactos técnicos existentes en Linux. El escáner lee cabeceras GGUF y metadatos escalares iniciales acotados, agrupa shards Safetensors, reconoce marcadores LoRA, configuración y archivos de tokenizer/licencia. Omite enlaces y reparse points; los pesos enlazados de un caché de Hugging Face pueden requerir inspección manual. Los blobs Ollama sin extensión requieren el inventario del runtime local. Un encabezado válido sólo identifica el formato.

Ejecutar `workstation.ps1 inventory` y consultar el JSON privado en la ruta anunciada. Para cada candidato confirmar revisión, tamaño/arquitectura, cuantización, integridad de shards, template, licencia, RAM/VRAM y tarea con una prueba local. Un indicador de tamaño de GGUF no acredita parámetros exactos. Revisar la tarjeta para distinguir embeddings, razonamiento y generación de código. Mantener pesos, identificadores y rutas en la estación. Usar GGUF para inferencia; seleccionar pesos Transformers completos y compatibles para QLoRA.
